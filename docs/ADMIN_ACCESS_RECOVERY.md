# بازیابی دسترسی مدیر

## حالت عادی: کاربر یا کارمند رمز را فراموش کرده است

1. مدیر کل وارد بخش «کاربران و دسترسی‌ها» می‌شود.
2. کنار حساب موردنظر، گزینه بازنشانی رمز را انتخاب می‌کند.
3. سامانه یک رمز موقت یک‌بارنمایش تولید می‌کند.
4. رمز از یک کانال امن به کاربر تحویل داده می‌شود.
5. کاربر در اولین ورود باید رمز شخصی جدید تعیین کند.

رمز عبور هیچ‌گاه در جدول‌های برنامه ذخیره یا برای مدیر نمایش داده نمی‌شود.

## حالت اضطراری: مدیر کل رمز را فراموش کرده است

در MVP، حساب‌ها ایمیل واقعی ندارند و بازیابی عمومی ایمیلی عمداً فعال نیست. برای جلوگیری از ایجاد مسیر ناامن، بازیابی مدیر کل باید از داشبورد Supabase انجام شود:

1. وارد پروژه `Dolphin Abi` در Supabase شوید.
2. از بخش Authentication، کاربر متناظر با مدیر کل را پیدا کنید.
3. رمز موقت قوی جدید تعیین کنید.
4. در جدول `profiles`، مقدار `must_change_password` همان کاربر را `true` کنید.
5. مدیر با رمز موقت وارد شده و بلافاصله رمز شخصی تعیین می‌کند.

اگر دسترسی به Supabase نیز از دست رفته باشد، ابتدا باید مالکیت حساب Supabase بازیابی شود. هیچ secret key نباید برای حل این وضعیت در مخزن یا پیام‌رسان قرار گیرد.

## پیش از ورود کاربران آزمایشی

- حداقل دو مدیر کل فعال داشته باشید تا یک حساب پشتیبان وجود داشته باشد.
- مشخصات ورود موقت را در پیام عمومی یا گروهی ارسال نکنید.
- پس از تحویل رمز، تأیید کنید کاربر تغییر رمز اولین ورود را انجام داده است.
- برای نسخه پس از MVP، ایمیل واقعی و جریان بازیابی کنترل‌شده اضافه شود.
